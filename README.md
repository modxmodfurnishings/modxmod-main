# MODxMOD Main Project

## Rationale

Furniture and devices should adapt to people, not the other way around.

MODxMOD FURNISHINGS strives to create an open system (the Open Furnishings System) of integration between hardware-to-hardware components, as well as hardware-to-software and software-to-software components.  As an organization, we will provide these components and specifications, but the open source nature of this project allows anyone to build upon and adapt the technology and plans to their personal needs.

In short: everyone can be a creator, everyone can interoperate, and no one organization will own the interoperation technology.

## System Parts

The Open Furnishings System describes several pieces:

- Naming and templates for parts
- Naming and templates interfaces
- Naming and workflows for interactions
- Templates for various solutions

## Designs that change

Designs in this repository are subject to change, especially those in the Labs folder.
